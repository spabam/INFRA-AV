# Bundled font sources

Inter variable normal and italic: upstream Inter v4.1, unchanged WOFF2 files
from https://github.com/rsms/inter/tree/v4.1/docs/font-files.
License: Inter-LICENSE.txt (SIL Open Font License 1.1).

JetBrains Mono regular and bold: upstream v2.304, unchanged WOFF2 files
from https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts.
License: JetBrainsMono-OFL.txt (SIL Open Font License 1.1).

These files are local application assets. Installation and browsing do not
contact a font CDN. The release manifest records each file's SHA-256 digest.
System fonts provide script coverage and a fallback when web fonts are blocked.
